What it does

Everything a message needs before it leaves the bytes.

One package, five jobs. Each takes a header or a body and hands back data you can act on.

◧

Media types

media_type reads Content-Type into an essence and ordered parameters, then writes it back with correct quoting.

⌗

The registry

guess_type names the type a filename implies; guess_extension gives the extension people use for a type.

⇥

Content-Disposition

Build and parse the header that names a download, with filename* (RFC 5987) for names that escape ASCII.

✂

Multipart

multipart splits any multipart body into parts — the shape an email and a form upload share.

▤

Form data

formdata reads multipart/form-data into text fields and file uploads, distinguishing them the way the wire does.

◒

Bounds

Limits caps part count and part size. A body over its bound is refused whole, never truncated.

Quick start

Add it, then parse a header.

shell
moon add moonbitstack/moonmime
main.mbt
let mt = @moonmime.media_type("text/html; charset=utf-8")
println(mt.essence)
println(mt.type_())
println(mt.param("charset").unwrap_or(""))
text/html text utf-8
