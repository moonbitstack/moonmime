Values

pub fn content_disposition(StringView, inline? : Bool) -> String

The Content-Disposition value naming filename (RFC 6266).

A name that is plain ASCII goes out quoted; anything else — a space is not enough, but an accent, a quote, a newline, a byte outside ASCII — goes out as filename*, the only form that carries them and the only one a name cannot break out of.

inline asks the browser to show the content rather than save it.

example
println(@moonmime.content_disposition("menu.pdf"))
println(@moonmime.content_disposition("receta \"de la abuela\".pdf"))
attachment; filename="menu.pdf" attachment; filename*=utf-8''receta%20%22de%20la%20abuela%22.pdf
pub let fallback : String

What a response says it is when nothing says otherwise.

pub fn formdata(BytesView, StringView, limits? : Limits, strict? : Bool) -> Form raise Refused

Parse a multipart/form-data body (RFC 7578) given its boundary.

A part goes into the files when its Content-Disposition carries a filename and into the fields when it does not, which is the only thing distinguishing them on the wire.

example
let form = @moonmime.formdata(body, "----edge")
println(form.field("recipe").unwrap_or(""))  // chiles en nogada
chiles en nogada
pub fn guess_extension(StringView) -> String?

The extension most people use for a media type, with its dot; None when the type is not in the table. Parameters are ignored, so the value may be given with its charset.

pub fn guess_type(StringView) -> String

The media type a filename's extension implies; fallback for anything else.

The last dot wins, so archive.tar.gz resolves on gz. The table is the common part of the IANA media-type registry; a caller that knows its type names it rather than hoping the extension does.

example
println(@moonmime.guess_type("factura.PDF"))        // application/pdf
println(@moonmime.guess_type("archive.tar.gz"))     // application/gzip
application/pdf application/gzip
pub let limits : Limits

A thousand parts of a megabyte each — a bound wide enough for a usual form upload, tight enough to stop a body from asking for more than a server has. A caller that knows its own shape should say so.

pub fn media_type(StringView) -> MediaType

Parse a header value into a media type. Lenient: anything that is not a parameter is left out, so an empty or foreign value yields an empty essence rather than an error.

example
let mt = @moonmime.media_type("text/plain; charset=utf-8")
println(mt.essence)                    // text/plain
println(mt.param("charset").unwrap_or(""))  // utf-8
text/plain utf-8
pub fn multipart(BytesView, StringView, limits? : Limits, strict? : Bool) -> Array[Part] raise Refused

Split a multipart body into its parts (RFC 2046 §5.1) given its boundary.

Preamble and epilogue are dropped; the two CRLF before each delimiter belong to the delimiter, not to the part. A body that stops making sense returns what it read so far, unless strict says to refuse it.

example
let parts = @moonmime.multipart(body, "b")
println(parts.length())                       // 1
println(parts[0].header("content-type").unwrap_or(""))  // text/plain
1 text/plain

pub(all) struct Disposition

A parsed Content-Disposition header (RFC 6266).

kind is the lowercased disposition type — inline, attachment, form-data — and params the rest, names lowercased and quoted values unquoted.

kind : String
params : Array[(String, String)]
pub fn Disposition::filename(Self) -> String?

The filename the disposition names, filename* first (RFC 6266 §4.3).

A filename* that is not UTF-8 falls back to the plain filename.

pub fn Disposition::param(Self, StringView) -> String?

A parameter by lowercased name.

pub fn Disposition::parse(StringView) -> Self

Parse a header value. Lenient, like [media_type].

example
let d = @moonmime.Disposition::parse(
  "attachment; filename=\"fallback.txt\"; filename*=utf-8''r%C3%A9sum%C3%A9.txt",
)
println(d.filename().unwrap_or(""))  // résumé.txt
résumé.txt

pub(all) struct Limits

What a body is allowed to be.

A body arrives from whoever sent it, so both bounds are needed: a million empty parts and one enormous part are different ways of asking a server to allocate more than it has.

pub(all) struct MediaType

A media type: text/plain; charset=utf-8.

essence is the lowercased type/subtype; params keeps the parameters in order, names lowercased and quoted values unquoted. A malformed parameter is dropped rather than guessed at.

Errors

pub(all) suberror Refused

Why a body was not read as a form.

A body over its bounds is refused whole rather than truncated: a handler given the first thousand parts of a larger body would be answering a request nobody sent.

Parts(limit~ : Int32)

More parts than allowed.

Part(limit~ : Int32, got~ : Int32)

One part longer than allowed.

Malformed(at~ : Int32)

A body that stops making sense at this offset. Only raised under strict; otherwise the parts read so far are returned.

NotAForm(content_type~ : String)

A content type that is not a form encoding, for whoever picks a decoder by Content-Type and was asked to say so.
